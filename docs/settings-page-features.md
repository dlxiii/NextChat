# Settings 页面功能说明

本文档介绍 `/#/settings` 页面当前可用的功能分区，以及每个配置项的用途。

> 说明：部分分区支持通过环境变量动态显示/隐藏，详见文末“环境变量开关”。

## 1. 通用界面与交互

- **头像**：设置用户头像（Emoji）。
- **发送键**：设置发送消息快捷键（Enter / Ctrl+Enter 等）。
- **主题**：自动、浅色、深色。
- **语言**：切换界面语言。
- **字体大小**：调节全局文字大小。
- **字体族**：自定义界面字体。
- **自动生成标题**：创建对话后自动生成会话标题。
- **发送预览气泡**：发送时显示预览气泡。
- **Artifacts 开关**：开启/关闭 Artifacts 相关能力。
- **代码折叠开关**：开启/关闭代码块折叠功能。

## 2. 数据与同步（可通过环境变量隐藏）

- **云端数据**：查看上次同步时间与同步提供方，支持打开配置并手动同步。
- **本地数据**：查看本地数据概览（会话、消息、提示词、面具），支持导出/导入。
- **同步配置弹窗**：支持多种云存储方案（如 WebDAV、Upstash 等）的参数配置。

## 3. 面具（Mask）相关

- **显示面具启动页**：控制新建会话时是否显示面具启动页。
- **隐藏内置面具**：是否隐藏内置面具。

## 4. 提示词（Prompt）相关

- **禁用提示词联想**：关闭输入时提示词联想。
- **提示词列表管理**：查看内置/自定义提示词数量，进入编辑弹窗管理。

## 5. 模型与接入配置

### 5.1 服务接入与 API 配置

- **立即开始（SaaS 引导）**：跳转到托管服务入口（可通过环境变量隐藏）。
- **访问码**：输入访问控制码（当服务端启用访问控制时可见）。
- **自定义 Endpoint 开关**：是否使用自定义 API 配置（可通过环境变量隐藏）。
- **Provider 选择**：选择 OpenAI / Azure / Google / Anthropic / Baidu / ByteDance / Alibaba / Tencent / Moonshot / DeepSeek / xAI / ChatGLM / SiliconFlow / 302.AI 等。
- **各 Provider 参数项**：按供应商展示对应的 URL、Key、Version 等字段。
- **余额查询**：在允许时可手动触发余额/用量刷新。
- **自定义模型字符串**：通过逗号输入自定义模型列表（可通过环境变量隐藏）。

### 5.2 模型高级参数（可通过环境变量隐藏）

- **模型参数设置**：包括模型名、温度、Top P、历史消息条数等。
- **对话摘要模型**：用于长对话压缩/摘要的模型与提供方配置。
- **系统提示词注入、输入模板等**：高级行为控制。

## 6. 实时聊天（可通过环境变量隐藏）

- **实时聊天开关**。
- **Provider / 模型 / API Key 配置**。
- **Azure 实时参数**（endpoint、deployment）。
- **温度、语音等实时会话参数**。

## 7. 文本转语音 TTS（可通过环境变量隐藏）

- **启用文本转语音**：总开关。
- **自动播放**：生成语音后自动播放。
- **引擎、模型、音色**：TTS 相关核心配置。
- **速度**：语速滑杆控制。

## 8. 更新（可通过环境变量隐藏）

- **当前版本**：显示当前客户端版本号。
- **检查更新**：手动检查是否存在新版本，并可跳转更新。

## 9. 危险操作

- **重置设置**：恢复默认配置。
- **清空所有数据**：清空消息与设置。

## 10. 环境变量开关

以下变量用于控制 Settings 页面分区显示（默认隐藏，设置为 `1` 或 `true` 后显示）：

- `ENABLE_SETTINGS_SYNC_SECTION`：显示“云端数据 / 本地数据”。
- `ENABLE_SETTINGS_MODEL_SECTION`：显示“模型高级参数（含对话摘要模型）”。
- `ENABLE_SETTINGS_REALTIME_SECTION`：显示“实时聊天”。
- `ENABLE_SETTINGS_TTS_SECTION`：显示“TTS（启用文本转语音、速度等）”。
- `ENABLE_SETTINGS_UPDATE_SECTION`：显示“当前版本 / 检查更新”。
- `ENABLE_SETTINGS_SAAS_SECTION`：显示“使用 NextChat AI（SaaS 引导）”。
- `ENABLE_SETTINGS_CUSTOM_ENDPOINT_SECTION`：显示“自定义接口（Custom Endpoint）”。
- `ENABLE_SETTINGS_CUSTOM_MODEL_SECTION`：显示“自定义模型名（自定义模型字符串）”。

可在 `.env` 中配置，或在部署平台环境变量中配置。
